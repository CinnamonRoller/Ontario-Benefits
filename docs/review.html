Rule review

Draft. These rules were written by an AI from Ontario's published policy directives. Nobody has checked them yet. Thank you for helping.

How to review (about 15 minutes for a first pass)

  1. Each card shows one rule, the exact sentence copied from the directive, and a link to the official page.
  2. Ask: Is this sentence copied correctly, and does it still match the live directive? Is the rule it describes right in practice?
  3. Press Looks right, Wrong or Not sure. Add a note if it helps, especially for Wrong. Notes like "in practice caseworkers do X" are very valuable.
  4. Your answers are saved only in this browser. When you are done (or want to stop), press Download my review and send the file to the project. You can come back later and load it again.

Some rules are marked discretionary: the directive leaves the decision to a caseworker. For these, the tool only says "ask a caseworker". Tell us if that is the right way to handle them.
